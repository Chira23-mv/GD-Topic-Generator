# GD Topic Generator

A small Streamlit app that gives you a random group-discussion topic and a countdown timer to practice speaking on it.

## Features
- Random GD topics across 5 categories (Current Affairs, Technology, Social Issues, Business & Economy, Abstract)
- Adjustable timer (1-5 minutes) with live countdown and progress bar
- History of your last 10 topics
- Easy to extend: add topics in `topics.json`

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech stack
Python, Streamlit
